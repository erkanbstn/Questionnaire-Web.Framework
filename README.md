# Anket

Yönetici, şirket ve personelin dinamik anket tanımadığı ve sonuçları gördüğü web uygulaması.

## Ne var

Üç rolün paneli ayrı controller'lardadır. Code First migration'ı açılıştan önce çalıştırılmalıdır.

## Çalıştırma

Çözümü Visual Studio ile açıp başlangıç projesini çalıştırın. Veritabanı kullanan projelerde bağlantı dizesini kendi ortamınıza göre güncelleyin.

## Yığın

.NET Framework MVC, Entity Framework ve katmanlı yapı.
